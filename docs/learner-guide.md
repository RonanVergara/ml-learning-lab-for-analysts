# Learner guide

## What this review build teaches

Milestone 1 contains one complete Foundations lesson: deciding whether an analyst request needs reporting, a fixed rule, or supervised machine learning. The full Python/pandas orientation and remaining Foundations lessons belong to Milestone 2.

## Navigation

Navigation is always open. Recommended order is Start here → Understand → Explore → Code → Check. You may move between stages without losing saved completion.

## Activities

Activities use the simplest interaction that fits the concept. The first activity is a scenario sorter rather than a chart because the goal is decision framing.

## Bounded code labs

Read-only context explains the trusted setup that already exists. Edit only the marked region—three lines in the first lesson—and run the checkpoint. The app executes setup first, checks only the bounded edit, and gives checkpoint-specific feedback. Reset restores the working starter values.

The runner allows only lesson-specific operations, then uses a child process, timeout, output limit, and process-tree cleanup. These features protect the learning experience from mistakes; they are not a secure sandbox for untrusted code.

## Progress

Explore, Code, and Check each create one piece of lesson evidence. Completing all three marks the vertical-slice lesson complete. Progress lives only on your machine.

Use **Progress & settings** to:

- Download a versioned progress JSON.
- Preview and restore a compatible export.
- Reset progress after an automatic backup.

Restore replaces the one local profile; it does not merge profiles.

## Evidence package

The Milestone 1.1 ZIP is pipeline evidence, not a completed course project. It includes readable CSV, PNG, XLSX, IPYNB, Markdown, HTML, and JSON artifacts. Extract it before opening the notebook so its relative `data/sample_cases.csv` path works.

## Course-completion status

The review build reports **In progress**. Later milestones will calculate completion from the orientation, three module badges, and three projects. The application does not generate a certificate.
