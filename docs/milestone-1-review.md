# Milestone 1 review checklist

Milestone 1 must be reviewed and explicitly approved before Milestone 2 begins.

## User walkthrough

- Launch with `Launch ML Learning Lab.cmd`.
- Inspect Home and Start here.
- Complete all four stages of Learn: F1.
- Restart and confirm lesson evidence remains.
- Export progress, reset, preview the export, and restore it.
- Download and inspect the evidence ZIP.

## Evidence expected

- Passing automated tests.
- Validated ZIP with CSV, PNG, XLSX, IPYNB, Markdown, HTML, and JSON.
- Exact Python 3.13 dependency lock.
- Local state and rotated logs under `%LOCALAPPDATA%\MLLearningLab`.
- All six documentation deliverables.

## Intentional limitations

- Only the orientation entry and Foundations lesson F1 are implemented.
- No module quiz or full synthetic BPO project is part of Milestone 1.
- The evidence ZIP is a minimal pipeline proof, not Project 1.
- Restore supports the exact Milestone 1 schema/content version; migrations begin when a later version needs them.
- Only Windows 11 and CPython 3.13 are supported.

After review, record approval before adding the rest of the orientation or Foundations module.
